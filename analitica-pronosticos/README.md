# Métodos Cuantitativos & Análisis de Pronósticos de Demanda

Módulo de analítica cuantitativa para la evaluación de modelos de pronósticos de demanda en operaciones, cálculo de indicadores de error (MAD, MSE, RMSE, MAPE, WMAPE, FACC) y tableros interactivos de decisión.

---

## 🌐 Despliegue en Producción
* **URL de Producción**: [https://analisispronosticos.vercel.app](https://analisispronosticos.vercel.app)

---

## 📊 Componentes del Proyecto
* **`Analisis_pronosticos.html`**: Dashboard interactivo con análisis comparativo de modelos, métricas WMAPE y capacidad predictiva.
* **`dashboard_pronostico.html`**: Tablero directivo complementario para revisión de pronósticos.
* **`pronostico_core.py`**: Motor matemático en Python para cálculo de suavización exponencial, promedios móviles y regresiones lineales.
* **`build_modelos_pronostico.py`**: Pipeline de ingesta y generación de datos consolidados en JSON/Excel.
* **`Caso Real Pronóstico - Modelos.xlsx`**: Datos históricos y modelos calibrados de demanda operativa.
