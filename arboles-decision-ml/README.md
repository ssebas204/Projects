# Árboles de Decisión para Toma de Decisiones Bajo Incertidumbre

Aplicación interactiva y marco metodológico para la estructuración y resolución de problemas de decisión secuenciales en operaciones, cálculo de Valor Esperado Monetario (VEM) y análisis de riesgo.

---

## 🌐 Despliegue en Producción
* **URL de Producción**: [https://arboldecisionapp.vercel.app](https://arboldecisionapp.vercel.app)

---

## 🌲 Componentes del Proyecto
* **`arbol_decision_app.html`**: Aplicación web interactiva que simula nodos de decisión, probabilidades de eventos, payoffs y ramas óptimas de decisión.
* **`arbol-decision.png`**: Diagrama estructural de alta resolución del árbol de decisión.
* **`Plantilla_Arbol_Decision.xlsx`**: Matriz analítica para parametrización de probabilidades y costos/ingresos por alternativa.
